Talk to Insightly in plain English

The Insightly SE MCP connects Claude to any of our Insightly demo environments. Ask questions, prep demo data, and update records by typing what you want — no clicking through the CRM.

What’s new Big update since the last version — if you installed a while ago, this is what changed

New: a visual dashboard

  • Ask “show me the Insightly dashboard” and you get an interactive panel right in the chat — a tile per object with live record counts, instead of a wall of text.
  • Click any tile to see that object’s newest records, or its full field list (including the valid dropdown values, which is what stops wrong data being created).
  • Custom objects get their own cards, named the way your environment names them, with record counts.
  • An Explore row for the setup behind a demo: custom objects, pipelines and their stages, and users with their email addresses.

New: jump straight into Insightly

  • Record names and IDs are clickable and open that record in Insightly in a new tab, in the side-panel view so you keep your place in the list.
  • A panel’s title opens the full list view for that object.

New: work across several environments

  • Save each demo env once, then switch by name — “switch to my healthcare env”. You never paste an API key into the conversation again.
  • In the dashboard, the environment tag is the picker — click it for every saved env, with the panel reloading in place.
  • Add, rename and remove environments from that same menu. Removing only forgets the key saved on your Mac; nothing in Insightly changes.

Bigger jobs, no limits

  • Export a whole object however large it is — “export all my contacts” now runs in the background and reports progress, instead of stopping at a few thousand records.
  • Create records in bulk without a per-request cap — “seed 200 sample contacts” just works.
  • You can check on, or cancel, anything running.

Better answers, fewer surprises

  • Counts are now exact. “How many opportunities do I have?” reads the real total rather than guessing from the first page.
  • “Newest” really means newest. Insightly hands records back oldest-first, so recent-record lists were showing the oldest ones. They now rank on whichever is later, created or updated — so something you made this morning appears at the top.
  • Newest by any date you like — “the 50 most recently closed opportunities” ranks on the actual close date, and does it without trawling the whole object.
  • Lookup fields become names. A list of organisation IDs can be turned into the organisation names in one step, instead of fetching every record to read one word.
  • Search finds more: partial matches, and searching across every field (“anything mentioning Acme”), not just exact names.
  • Link records together — put a contact into an organisation, and see what a record is already linked to.
  • Tickets and products work (they were silently unavailable before), plus far more of the CRM is reachable.
  • Safer edits: updates can detect if someone changed the record while you were looking at it, rather than overwriting their work.
  • Big answers no longer vanish. A result too large for the chat used to be thrown away with a size warning; now it comes back trimmed, and says how to get the rest.
  • See your API budget — the dashboard shows how many calls you have left today, so a big job never stops for a mystery reason.

Reliability & install

  • Fixed the breakage where a background update from an outside component stopped new installs from working at all. Versions are now locked so that cannot recur.
  • Fixed the greyed-out Install button some Macs showed (it wrongly demanded Python).
  • Windows: the installer now includes a Windows path — not yet confirmed on a real Windows machine, so use the step-by-step guide there and tell Luke how it goes.
  • Speed: reuses one connection and paces itself under Insightly’s limits, so record-heavy environments feel much quicker.

Install it

Four steps, one time. You'll need your Insightly API key — in any demo environment, click your profile picture (top right) → User Settings → API and copy the key.

  1. 1

    Install the helper (one Terminal command)

    The extension uses a small runner called uv. Open Terminal (press ⌘Space, type “Terminal”, press Return). Paste this whole line and press Return:

    curl -LsSf https://astral.sh/uv/install.sh | sh && echo "YOUR UV PATH: $HOME/.local/bin/uv"

    When it finishes it prints a line starting YOUR UV PATH: — keep Terminal open; you’ll copy that path in step 3. That’s the only Terminal step.

    Don’t be alarmed if typing which uv in this same window says “not found” — the install only registers in new Terminal windows. You don’t need to check anything; just copy the printed path.

    Homebrew user? brew install uv works too — then in step 3 the pre-filled path is already correct and you can skip the path part.

  2. 2

    Download and double-click the extension

    Click the download button above — the file lands in your Downloads folder. Double-click it and Claude opens an install dialog.

    Double-click doesn’t open Claude? In Claude go to Settings → Extensions → Advanced settings → Install extension… and pick the file from Downloads.

  3. 3

    Fill in the install dialog (3 fields — you only change 2)

    Insightly API key: paste the key you copied (profile picture → User Settings → API). Claude stores it securely — it never appears in chat.

    Path to uv: replace what’s there with the path Terminal printed in step 1 (the part after “YOUR UV PATH:”, like /Users/yourname/.local/bin/uv). Used Homebrew instead? Leave it as is.

    Leave Insightly pod as na1 unless your Insightly URL says otherwise.

  4. 4

    Restart Claude — fully

    Press ⌘Q (closing the window isn’t enough), then reopen Claude.

✓

Check it worked: in a new chat, type “What’s in this Insightly env?” — you should get back a table of real record counts. The very first question can take up to a minute — it’s downloading its own copy of Python and a few packages, one time. After that it’s fast. Nothing after a minute or two? See the fixes below.

!

Already have an Insightly connector switched on? Some accounts have a company-managed Insightly connector (it shows as Custom under Settings → Connectors, with a name like “Insightly (Internal Release)”). It offers some of the same actions by the same names, so Claude may answer from whichever it picks — and the answers can differ. While you’re trying this out, turn the other one off in the chat’s tools menu (the ⚒ icon under the message box).

What you can do — just say it

These are prompts, not commands — phrase them however you like. Claude picks the right tool.

Get oriented

“What’s in this demo env?”Record counts across contacts, orgs, leads, opportunities, tickets, products, and more — in one shot.
“How many open opportunities do we have?”Real totals, not a guess from the first page.
“List my 10 most recently updated leads.”Genuinely the most recent — ranked on created or updated, whichever is later.
“Which env am I connected to?”Shows the environment, region, and tool version.

Prep a demo

“Seed 15 sample healthcare contacts with realistic intake statuses.”Batch-creates records using the env’s real custom fields and dropdown values.
“Create an organisation called Acme Rockets and a contact Jane Doe in it.”Builds linked records in one go.
“What fields does the Opportunity object have here?”Lists standard and custom fields — including valid dropdown options.
“Find and delete the contacts named MCP-Test.”Cleanup after a demo. Deletes always ask for confirmation first.

Find & update

“Find jane@acme.com and add a note that we spoke today.”Looks up the contact and attaches the note.
“Find anything mentioning Acme in opportunities.”Searches across every field, not just names.
“Update Jane Doe’s intake status to Admitted.”Edits the record with a valid option value.
“Switch to my healthcare demo env.”Changes environment by name. The key stays saved on your Mac — it never goes in the chat.

How it works

Nothing is hosted anywhere — the whole thing runs on your Mac.

You ask in chat“Seed 15 sample contacts.”
→
Claude picks a toolThe extension gives Claude 30-plus Insightly actions: list, search, create, update, count…
→
Your Mac calls InsightlyRequests go straight to Insightly’s API using your key, and results come back into the chat.
  • Your key stays local. It lives in Claude’s secure settings on your Mac and is never shown in chat.
  • Full read/write — it can create, edit, and delete. Deletes always require an explicit yes.
  • Demo environments only. Point it at demo envs, not customer or production data.
  • It paces itself under Insightly’s API rate limits, so big requests (“list everything”) just take a few extra seconds.

If something’s off

SymptomFix
Claude doesn’t seem to have Insightly tools Usually the API key field was left empty during install (Claude skips the extension silently). Open Settings → Extensions → Insightly SE MCP, fill the key, then ⌘Q and reopen. Also confirm you’re in the desktop app, not a browser.
“Unable to connect” the moment you first enable it Common on the very first start — the app sometimes launches before the settings you just typed are applied. Toggle the extension off and on (Settings → Extensions), or ⌘Q and reopen. One retry fixes it; no need to touch Terminal.
First question never answers, or errors mentioning Python Open a new Terminal window and run uv python install 3.12 — it installs the Python the tool runs on. When it finishes, ⌘Q Claude, reopen, ask again. (Usually automatic — this is the manual nudge.)
“Server disconnected” error The Path to uv setting doesn’t match where the helper actually is on your Mac. Open a new Terminal window, run which uv, copy the path it prints into Settings → Extensions → Insightly SE MCP → Path to uv, then ⌘Q and reopen.
Answers look wrong, or come from somewhere else Another Insightly connector is probably switched on alongside this one — check Settings → Connectors for a Custom entry such as “Insightly (Internal Release)”. It shares several action names, so Claude may answer from either. Turn the other one off in the chat’s tools menu (⚒ under the message box), or disconnect it in Settings. To confirm which one answered, ask: “Run the Insightly connection_info tool.”
Something worked before and broke, or you want the newest version Re-download using the button above (it always serves the newest build), double-click to reinstall over the top — no need to remove the old one — then ⌘Q and reopen. To see what you’re on, ask: “Run the Insightly connection_info tool.”
